# Atelier Auto

A website for **Atelier Auto**, a fictional premium car-detailing studio. Built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```

## Notes

- Photography is loaded from Unsplash's CDN, so an internet connection is needed to see images.
- All business details (address, prices, phone, email) are fictional. The booking form is a demo and sends nothing.
